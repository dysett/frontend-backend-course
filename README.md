# Frontend- та Backend-технології вебзастосунків

Навчальні проєкти на Node.js, Express і MongoDB, матеріали курсу, колекції Postman та сценарій демонстрації. Кожен застосунок має власні залежності, конфігурацію та демонстраційну базу.

## Проєкти

| Проєкт | Призначення | Локальна адреса |
| --- | --- | --- |
| [RESTful-сервіс](restful-service/README.md) | JSON API, CRUD, DAO, видача та повернення книжок | http://127.0.0.1:3002 |
| [Товстий клієнт](thick-client/README.md) | React, Bootstrap, адміністративні сеанси та автоматичне AJAX-оновлення | http://127.0.0.1:3003 |
| [Пособник спамера](posobnyk-spamera/README.md) | Адресна книга, підготовка листів, журнал розсилок, Pug | http://127.0.0.1:3000 |

## Запуск після завантаження

Потрібні Node.js 22.12 або новіший та npm. Для кожного потрібного проєкту відкрийте окремий термінал у його папці та виконайте:

```powershell
npm ci
npm run demo
```

Перший запуск може завантажити сервер MongoDB. Деталі та можливість використання власної MongoDB описані в README відповідного застосунку. Зупинка — Ctrl+C.

Демонстраційний вхід до адміністративного інтерфейсу «Товстого клієнта»: **admin / DemoLibrary!2026**. Цей загальнодоступний навчальний обліковий запис створюється лише в локальному режимі `demo`.

## Матеріали для перевірки

- [Колекція «Бібліотека — API»](postman/Бібліотека.postman_collection.json): запити R01–R12 для RESTful-сервісу й T01–T06 для сеансів та доступу другого застосунку.
- [Сценарій демонстрації двох проєктів](presentation-output/Сценарій%20демонстрації%20двох%20проєктів.md): послідовність дій і текст пояснень українською на 10 хвилин.
- Документи та презентації в корені — матеріали курсу.

Колекцію JSON потрібно імпортувати в Postman через Import. Перегляд JSON-файлу в редакторі не виконує запити.

## Перенесення на інший комп'ютер

Завантажте або склонуйте репозиторій, додайте його папку до локального проєкту Codex та встановіть залежності потрібних застосунків. У сценарії є абсолютні посилання на локальні файли. Для їх збереження на іншому Windows-комп'ютері використовуйте той самий шлях папки:

```text
C:\Codex\Front-end and back-end web application technologies
```

Локальні бази `.data`, персональні `.env`, сформовані листи `outbox`, залежності `node_modules`, кеші та архіви не входять до Git. Після першого запуску порожні демонстраційні бази отримують початкові приклади. Для перенесення власних записів потрібне окреме перенесення бази даних.
